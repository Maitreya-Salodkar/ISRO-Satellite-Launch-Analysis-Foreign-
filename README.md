# 🚀 ISRO Foreign Satellite Launch Analysis

An interactive **Power BI dashboard** analyzing foreign satellites launched by the **Indian Space Research Organisation (ISRO)**. The dashboard provides a visual overview of satellite launch activity, countries served, launch vehicles, payload capacity, and yearly launch trends.

## 📊 Dashboard Overview

The dashboard, titled **"FOREIGN SATELLITES LAUNCHED BY ISRO"**, provides interactive analysis through KPI cards, charts, and filters.

### Key Metrics

- 🚀 **Total Satellites Launched**
- 🌍 **Countries Served**
- 📅 **Maximum Satellites Launched in a Day**
- 🛰️ **Unique Launch Vehicles (SLVs)**
- 📦 **Maximum Payload Launch**

### Visualizations

- **Year-wise Satellite Launch Trend** – Tracks the number of foreign satellites launched by ISRO over the years.
- **Top Countries** – Displays the countries with the highest number of satellites launched through ISRO.
- **Launch Vehicle Analysis** – Compares satellite launches across different launch vehicles.
- **Year Filter** – Allows users to analyze launches for specific years.
- **Launch Vehicle Filter** – Enables interactive filtering based on launch vehicle.
